# LIBRARY BOOK TRACKER

### Description
The Library Book Tracker is a simple Python program for library books management such as book inventory, book borrowing, and book returning.

### How to Run
1. Install Python on your computer.
2. Open the project folder using any appropriate code editor or IDE that supports Python (VS Code, Thonny, PyCharm, etc.)
3. Open the terminal.
4. Run the command `python main.py`
